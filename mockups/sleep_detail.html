Settled — stage palette

Oura-like is now the default: blues for the three sleep stages, cream for awake. Toggle to the old _STAGE_BAND to compare.

Coral for awake made normal wakefulness rhyme with the coral this screen already spends on "Pay attention" and the HIGH sleep-debt pill. Changing _STAGE_BAND also updates the Insights Sleep Architecture tab, which reads the same constant — consistently.

Coverage — measured, not assumed

All seven contributors are at 100 % across 361 nights. Time in bed, light sleep, awake time, bedtime end and the hypnogram are 100 % too; HR, HRV, respiratory rate, SpO2 and temperature deviation all sit at 96–99 %.

So the gap isn't missing fields — it's missing nights. Only 361 of 1,124 calendar days have a sleep period at all. "No sleep period" is the empty state that will actually be seen; thin-coverage is a guard that should almost never fire.

Contributor rows

Raw value on the right, bar encodes the sub-score — Oura's own pattern, and better than showing both numbers. Qualitative labels ("Pay attention", "Optimal") where a number isn't meaningful.

Weight is deliberately not shown per row; coverage goes in the caption instead.

Not reproduced

Oura's Body Clock chronotype arc is proprietary — we hold a bedtime baseline but no chronotype model. The movement tick strip needs movement_30_sec, which isn't captured. Both omitted rather than approximated.

Scroll length

Twelve sections. If it drags, Breathing (§6) or HRV (§8) move to Insights — that's the intended release valve, and both are the least glanceable.
